# `time_value`

Type-safe time-value-of-money calculations — a `no_std`, zero-dependency core.

This crate is being rebuilt from nothing, one formula at a time. Each formula
arrives with the [Knowledge Bundle](../../docs/knowledge/) Concept that sources
it: where the definition came from, which convention was followed where sources
disagree, and the vectors that attest the implementation matches.

Nothing is implemented yet, so there is nothing to document here. This section
grows one operation at a time, and every example below is a doc test — this file
is the crate's documentation, so it is compiled and run rather than trusted.

## Relationship to the published `0.x` series

Versions `0.1.0`–`0.8.0` on crates.io are a separate, immutable history. This
line does not continue them, and nothing here is published.
